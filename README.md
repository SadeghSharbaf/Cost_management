# Cost Management

A Windows desktop expense-management application built with C# and Windows Forms.

## Features
- Record and manage expenses
- Organize expense-related information
- View reports through the application's forms

## Requirements
- Visual Studio with the .NET desktop development workload
- A compatible .NET SDK/runtime for the target framework declared in `Cost_management.csproj`

## Run
1. Open `Cost_management.csproj` in Visual Studio.
2. Restore dependencies.
3. Build and run the project.

## Repository Hygiene
Visual Studio user settings, `.vs/`, `bin/`, and `obj/` are local/generated files and should not be committed. Back up any local data before cleanup.
